## Project Abstract

**MBU RouteX: A University Transportation Management and Tracking Web Application**

University transportation management presents a significant operational challenge for institutions managing large student populations across multiple bus routes. Manual processes — paper-based attendance, phone-based complaints, and no real-time visibility — create inefficiencies for students, drivers, and administrators alike.

MBU RouteX is a Java-based web application developed to address these challenges at Mohan Babu University. Built on the Spring Boot framework with a MySQL backend, the system provides a centralized, role-based platform for university transportation management.

The application serves three distinct user roles: **Students**, who can access their assigned bus information, track their bus in real time, submit complaints, access emergency contacts, and use a personal QR code for digital attendance; **Drivers**, who can manage their bus status, view service details, report mechanical issues, and access schedules; and **Management**, who gain full operational visibility across the fleet — monitoring trips, managing complaints, tracking maintenance, and overseeing student-bus assignments.

The system features a professional, university-oriented interface designed around the MBU campus identity — incorporating the institution's campus imagery, a restrained teal/green color palette, and consistent design language across all role-specific dashboards.

MBU RouteX replaces paper-based attendance with QR code scanning, centralizes complaint reporting for both students and drivers, and provides management with live trip monitoring and maintenance tracking — delivering a practical, implementable transportation management solution for a real institutional context.

**Keywords:** University Transportation, Spring Boot, Role-Based Access Control, QR Attendance, Java Web Application, Bus Tracking, Complaint Management, MySQL
